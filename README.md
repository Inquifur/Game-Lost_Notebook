#游戏：寻找笔记本
一款使用 Ren’Py 制作的校园悬疑视觉小说。从一本失窃的笔记本出发，通过对话、照片与证据整理，逐步拼凑一场实验室事故背后的真相。
目前为 DEMO 版本。

# Game-Lost_Notebook
A school-setting mystery visual novel created using Ren’Py. Starting with a stolen notebook, you piece together the truth behind an incident through dialogue, photographs, and the organization of evidence. 
Currently available as a demo.
